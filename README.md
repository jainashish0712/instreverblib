# InstagramReverb

Studio-grade Reverb & Pitch Shifting Tweak for Instagram on iOS (LiveContainer compatible).

## Features
- Real-time Pitch Shifter (-4.0 to +4.0 semitones in 0.2 intervals, 0% tempo change).
- Freeverb/Pizzicato Reverb engine with 100% complementary dry/wet mix (`dry + wet == 100%`).
- Dual audio interception: CoreAudio `AudioUnit` and CoreAudio `AudioQueue` (Meta FNFPlayer for Reels/Stories).
- Draggable floating mini HUD (half-screen width, 11pt compact thumbs, `+` / `-` interval stepper buttons).
- Native system volume slider with Spotify Green / Neon tint.
